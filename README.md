# cgl-tauri

&emsp;Conway's Game of Life implementation on Rust using Tauri

---

## Description

&emsp;A remake of my CGL project, this time using the hybrid desktop framework **_Tauri_** to take advantage of a web tech stack that allows for the **design and rapid development of featurefull and intuitive UIs, while, at the same time, being able to use a low level backend** running almost natively on the OS for rendering and game logic processing.

## Development Requirements

- [pnpm](https://pnpm.io/installation) package manager.
- [Rust](https://rust-lang.org/tools/install/) development kit.
